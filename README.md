# Pokémon Champions 2D — 分割版

元の `Pokemon_Champions_2D_v18.5_Superpower_Stat_Drop_Fix.html` を、動作順を保ったまま複数ファイルに分割したプロジェクトです。

## ファイル構成

- `index.html` — ゲーム画面のHTML
- `css/` — 見た目のスタイル。元のCSSブロック順に読み込みます
- `js/offline-data.js` — 図鑑・技・特性・タイプなどの内蔵データ
- `js/app.js` — メインのゲーム処理
- `js/patches/` — v17.7以降の追加修正。元の読み込み順を維持しています

## 起動方法

すべてのファイルを同じフォルダー構成のまま置き、`index.html` を開いてください。
サーバーへ公開する場合は、このフォルダーを静的サイトの公開ルートにします。ビルド処理は不要です。

## 注意

- `js/patches/` の読み込み順を変更しないでください。後のパッチが前の処理を上書き・拡張する箇所があります。
- 図鑑データは `js/offline-data.js` に内蔵されています。外部データ取得は追加していません。
- 元のゲームの外部スプライト画像の読み込み仕様はそのままです。
- これはファイル整理版です。ゲーム内容の仕様変更や新機能追加は行っていません。
